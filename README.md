# Typing Dungeon

キーボード練習 × ローグライク。日本語ローマ字入力でモンスターと戦い、戦闘ごとにスキルを選んで強くなるブラウザゲームです。

## 遊び方

- 単語を打ち切ると攻撃。速く・正確に打つほど大ダメージ
- 敵の攻撃ゲージが尽きると防御フェイズ。猶予時間内に打てた分だけ被ダメージが減る
- ミスすると敵の攻撃が早まり、防御の猶予も減る
- 勝つたびに3つのスキルから1つを選ぶ
- 5戦で1ラウンド、3ラウンド目のボスを倒せばクリア
- 日本語入力（IME）はオフにして遊ぶ。Esc で一時停止

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # テスト
npm run build      # 型チェック + ビルド（dist/）
```

## 構成

| パス | 内容 |
|---|---|
| `src/romaji/` | ローマ字入力エンジン（表記ゆれ対応） |
| `src/data/words.ts` | 単語データ（表示テキスト + 読み） |
| `src/game/balance.ts` | バランス調整用の数値 |
| `src/game/battle.ts` | 戦闘ロジック（攻撃・防御フェイズ） |
| `src/game/skills.ts` | スキル定義（イベントフック方式） |
| `src/game/run.ts` | ラン進行（ラウンド・HP・スキル所持） |
| `src/ui/` | 画面（DOM） |
| `docs/DESIGN.md` | 設計書 |
