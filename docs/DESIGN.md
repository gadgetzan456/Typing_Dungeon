# Typing Dungeon 設計書

キーボード練習 × ローグライク。日本語ローマ字入力で敵と戦い、戦闘ごとにスキルを獲得してビルドを組み上げる。

## プラットフォーム / 技術

- ブラウザ（TypeScript + Vite、描画は DOM）
- ロジック（ローマ字エンジン・戦闘・スキル）は DOM から分離し、Vitest でテストする

## 画面構成

```
タイトル → [戦闘 → スキル選択] ×5 → ラウンドクリア → … → 3ラウンド目の5戦目に勝利でクリア
                     ↓ HP 0
                 ゲームオーバー
```

戦闘画面には「モンスター」「打つべき文字（表示テキスト / かな / ローマ字ガイド）」「キーボード（次に打つキーを強調）」を表示する。

## ラン構成

- 5戦で1ラウンド、3ラウンドでクリア（計15戦）
- 各ラウンドの5戦目はボス
- ラウンド中は HP を持ち越す
- ラウンドが切り替わるとき、**減っている HP の 50%** を回復する
- ラウンドが進むほど敵が強くなる

## 戦闘（リアルタイム）

```
[攻撃フェイズ] 敵の攻撃ゲージが減る間、単語を打ち続ける（1単語打ち切るごとに攻撃）
      ↓ ゲージが 0
[防御フェイズ] 防御ワードを猶予時間内に打つ → 速度・精度から防御率を決定
      ↓
[攻撃フェイズ] ゲージをリセットし、新しい攻撃ワードで再開（打ちかけのワードは破棄）
```

### 計算式（数値は `src/game/balance.ts` で調整）

- 速度は **かな/秒** で測る（ローマ字の打ち方で不公平にならないように）
  - 攻撃ワードの計測時間は「そのワードが表示されてからの時間」
- **攻撃ダメージ** = 基礎攻撃力 × かな文字数 × 速度係数 × 精度係数 × スキル倍率
  - 速度係数 = かな/秒 ÷ 基準速度（0.5〜2.0 にクランプ）
  - 精度係数 = ノーミスなら 1.2、ミスありは「正解打鍵率³」（下限 0.3）
- **防御率** = 0.7 × 進捗率 × 精度係数(最大1) ＋ 完走ボーナス（0.1 ＋ 0.1 × 残り時間率）
  - 上限 90%（スキルで変動）
  - 被ダメージ = 敵攻撃力 × (1 − 防御率)
- 防御ワードの猶予時間 = 1.0秒 ＋ かな文字数 ÷ ラウンドごとの基準速度

### ミスのペナルティ

- 精度係数が下がる
- 攻撃フェイズ中のミス：敵の攻撃ゲージが 0.3 秒ぶん余計に減る
- 防御フェイズ中のミス：防御の猶予時間が 0.4 秒減る
- 防御フェイズに切り替わってから 0.5 秒間はミスを判定しない（正しいキーは受け付ける）

## 単語

- かな 3〜12 文字。長いものは短文（寿司打のイメージ）
- データは「表示テキスト ＋ 読み（ひらがな）」で持ち、文字数（= 読みの文字数）で分類する
- 出現は文字数ごとの重みで抽選し、スキルが重みを変更できる

## ローマ字入力

- 1つのかなに対する複数の打ち方を受け付ける（し: si/shi/ci、ちゃ: cha/tya/cya など）
- 拗音は一括（kya）でも分割（kixya）でもよい
- 「ん」: `nn` / `xn`。次のかなが母音・や行・な行で始まらない場合は `n` 1回でもよい。語末は `nn` が必要
- 「っ」: 次の子音を重ねる（kka）、または `xtu` / `ltu` / `xtsu` / `ltsu`
- ローマ字ガイドは、プレイヤーが選んだ打ち方に追従して表示を切り替える

## スキル

戦闘に勝つたびに 3 つの候補から 1 つを選ぶ。同じスキルを重ねて取ると効果が強くなる（上限あり）。

持続時間は 3 種類あり、強さのバランスを変える。

| 持続 | 倍率・加算 | 方針 |
|---|---|---|
| 永続（ラン中ずっと） | 小さめ・重ねがけ可 | 後半ほど効く |
| 戦闘中 | 中くらい | 戦闘ごとにリセット |
| 単発（その攻撃のみ） | 大きい | 瞬間火力 |

スキルはイベントフック方式で実装する（単語抽選の重み・ダメージ計算・ミス時・防御結果・被弾時などに割り込む）。追加するときは `src/game/skills.ts` に定義を足すだけでよい。
